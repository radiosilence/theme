# @radiosilence/theme

This package is now `@radiosilence/koan-kit-web`, published from [`koan-kit-web/`](https://github.com/radiosilence/koan/tree/main/koan-kit-web) in the koan repository, beside its specification. Every control is shown at [ui.koan.rocks](https://ui.koan.rocks).

`@radiosilence/theme` 0.2.9 is the last release under this name, and `@radiosilence/koan-kit-web` 0.3.0 has the same contents. To move over, replace the package name in `package.json`, the stylesheet's `@import` and the `kit-check` path.

This repository is archived and keeps the history up to 0.2.9.
